1. Clone the repository:
   ```
   git clone <repository-url>
   cd ZDL
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
   (Note: Create a requirements.txt file with necessary packages like torch, torchvision, etc.)
